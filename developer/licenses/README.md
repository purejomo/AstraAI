# 외부 라이선스 원문

libvips와 관련 동적 라이브러리에 적용되는 GNU GPLv3/LGPLv3 원문이다. 프로젝트 자체의 이용 조건과 별개이며, 각 구성 요소의 라이선스가 우선한다.

출처: [SPDX License List](https://github.com/spdx/license-list-data/tree/main/json/details). 설치본에는 각 패키지의 README, 라이선스, 버전과 원본 저장소 정보도 함께 보관한다. libvips 구성과 원본 소스 정보는 [sharp-libvips](https://github.com/lovell/sharp-libvips)에서 확인할 수 있다.
