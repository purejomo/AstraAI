# AstraAI

내 문제를 만들고 풀며 오답을 복습하는 Windows 학습 앱입니다.

## 설치

**[AstraAI-Setup.exe 다운로드](https://github.com/purejomo/AstraAI/raw/refs/heads/main/AstraAI-Setup.exe)**

1. 위 설치 파일 하나를 내려받습니다.
2. `AstraAI-Setup.exe`를 실행해 설치합니다.
3. 바탕화면의 **AstraAI**를 열고 **나의 문제은행 → 샘플로 시작하기**를 눌러 사용해 보세요.

Windows 10/11 64비트(x64)용입니다. 설치 후에는 계정이나 인터넷 연결 없이 사용할 수 있습니다.
