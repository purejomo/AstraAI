# AstraAI · 나의 학습실

내 자료로 학습팩을 만들고, 개념 학습·퀴즈·오답 복습을 이어가는 개인 학습 앱입니다. 코드를 내려받은 누구나 자기 PC에서 개념과 문제를 직접 만들고 공부할 수 있습니다.

**현재 제공 버전은 개인 PC에 설치해 사용하는 방식입니다.** 앱을 열면 바로 내 학습실이 시작됩니다. 인터넷에서 여러 사람이 접속하는 운영 방식은 아직 지원하지 않습니다.

## 할 수 있는 일

- **나의 문제은행**: 화면에서 개념·4지선다 문제·정답·해설·플래시카드 작성 및 수정
- **자료 가져오기·내보내기**: JSON 파일 검증, 다른 설치본으로 학습팩 이동, ChatGPT용 프롬프트 만들기
- **개념 학습**: 요약, 핵심 내용, 자주 묻는 질문 읽기
- **문제 풀이**: 범위·문항 수 선택, 힌트, 채점과 해설
- **반복 학습**: 오답 노트, 복습 일정, 플래시카드, 시간 제한 모의고사
- **내 공부 관리**: 시험 목표, 하루 공부 시간, 학습 계획과 성취 기록

## 설치하고 시작하기

Git과 Node.js 22 이상을 준비하세요. 현재 실행 가능한 코드는 `feat/cloud-study-mvp` 브랜치에 있습니다. 저장소가 비공개이므로 다운로드하려면 접근 권한이 필요합니다.

Windows PowerShell에서 한 줄씩 실행하세요.

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\source" | Out-Null
Set-Location "$env:USERPROFILE\source"
git clone --branch feat/cloud-study-mvp https://github.com/purejomo/AstraAI.git
Set-Location AstraAI
npm.cmd ci
npm.cmd run build
npm.cmd start
```

`Ready`가 표시되면 같은 PC의 브라우저 주소창에 `http://localhost:3000`을 입력하세요. 사용하는 동안 터미널을 열어두고, 종료할 때는 `Ctrl+C`를 누릅니다. 다음에는 같은 폴더에서 `npm.cmd start`만 실행하면 됩니다.

이미 설치했다면 다시 복제하지 않아도 됩니다. 기존 `AstraAI` 폴더에서 `npm.cmd ci` → `npm.cmd run build` → `npm.cmd start`를 실행하세요. Windows의 `npm.ps1` 실행 정책 오류는 위와 같이 `npm.cmd`를 사용하면 해결할 수 있습니다.

macOS/Linux 설치, 업데이트, 백업 및 오류 해결은 [설치·사용 안내](docs/INSTALLATION.md)를 참고하세요.

## 첫 학습팩 사용하기

1. **나의 문제은행 → 새 학습팩 만들기**를 누릅니다.
2. 제목과 개념 요약·핵심 내용을 적습니다.
3. 문제와 보기 4개를 입력하고 정답·힌트·해설·오답 복습 안내를 작성합니다. 필요하면 문제와 플래시카드를 더 추가하세요.
4. **검증하고 미리보기**에서 내용을 확인하고 **내용과 정답을 확인했습니다**에 체크합니다.
5. **내 학습팩에 저장 → 바로 학습하기**를 누릅니다.
6. **문제 풀기 → 퀴즈 시작**으로 풀어보고, 틀린 문제는 **오답과 복습**에서 다시 공부하세요.

먼저 둘러보고 싶다면 **샘플로 시작하기**를 선택하세요. 관리자 계정이나 별도 게시·공유 대상 지정은 필요하지 않습니다.

## 문제를 수정하고 다른 설치본에 옮기기

**나의 문제은행 → 내가 만든 학습팩 → 수정하기**에서 내용을 고칩니다. 저장하면 새 버전이 적용되고 이전 풀이의 정답·해설과 복습 기록은 유지됩니다.

**JSON 내보내기**로 받은 `study-pack.json`을 다른 사람의 앱에서 **JSON 파일로 가져오기**로 열 수 있습니다. 학습팩 내용만 옮겨지며 개인 풀이 기록은 포함되지 않습니다. UTF-8 JSON, 최대 5MB·500문항을 지원합니다.

[문제은행 사용 안내](docs/QUESTION_BANK.md) · [학습팩 형식](docs/DATA_CONTRACT.md) · [예제 JSON](examples/sample-study-pack.json)

## 내 자료로 ChatGPT에서 문제 준비하기

직접 입력하는 대신 **ChatGPT에 사용할 프롬프트 만들기**를 이용할 수도 있습니다. 제목·목표·문항 수를 입력하고 복사한 프롬프트와 원본 PDF·이미지를 본인의 ChatGPT 대화에 첨부하세요. 받은 JSON을 가져와 정답·해설·출처를 확인한 뒤 저장하면 됩니다.

앱에서 ChatGPT로 자료를 자동 전송하거나 유료 AI API를 호출하지 않습니다. ChatGPT 없이 직접 작성하거나 샘플로도 사용할 수 있습니다. ChatGPT를 이용한다면 해당 서비스의 이용 조건이 적용됩니다.

## 다른 사람도 자기 문제은행을 만들 수 있나요?

코드에 접근할 수 있는 사람은 각자 내려받아 설치한 뒤 **자기 문제를 작성하고 바로 학습**할 수 있습니다. 학습팩과 기록은 설치본마다 따로 저장됩니다. 원래 운영자의 업로드를 기다리거나 계정을 발급받을 필요가 없습니다.

[독립 설치·코드 공유 안내](docs/SELF_HOSTING.md)에서 코드와 학습팩을 전달하는 방법을 확인하세요.

## 무료로 온라인에서 사용할 수 있나요?

개인·비상업용 소규모 운영에는 **Vercel Hobby + Supabase Free**의 무료 한도를 이용하는 방법이 있습니다. 직접 상시 서버를 켜둘 필요 없이 웹 주소로 접속하는 구성입니다. 사용량 제한과 휴면 정책이 있으며 무제한 무료는 아닙니다.

현재 설치본을 그대로 올리는 방식은 지원하지 않습니다. 온라인용 로그인·권한·공유 저장소를 갖춘 버전이 필요합니다. 현재 무료 조건과 준비 사항은 [온라인 운영 안내](docs/HOSTING.md)에 정리했습니다.

## 기록 보관

학습팩과 기록은 설치 폴더의 `.local/study.json`에 저장됩니다. 새로고침이나 앱 재실행 후에도 유지되지만, 이 파일을 삭제하면 기록도 사라집니다. 앱을 종료한 상태에서 `.local` 폴더를 별도로 백업하세요. 작성 중인 내용은 이 브라우저에 임시 보관되므로, 백업에 포함하려면 학습팩을 저장하거나 JSON을 내려받으세요.

이전 버전에서 업데이트하면 기존 학습팩과 기록을 이어 씁니다. 기본은 이전 학습자 1 기록이며, 학습자 2·3 기록이 있다면 **설정 및 도움말 → 이전 버전 기록 이어 쓰기**에서 선택할 수 있습니다. 기록을 자동으로 합치거나 삭제하지 않습니다.
