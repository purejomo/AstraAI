# AstraAI

GPT가 만든 문제 파일로 공부하고, 틀린 문제를 복습하는 Windows 앱입니다.

## 설치

**[AstraAI-Setup.exe 다운로드](https://github.com/purejomo/AstraAI/raw/refs/heads/main/AstraAI-Setup.exe)**

1. 설치 파일 하나를 내려받아 실행합니다.
2. 바탕화면의 **AstraAI**를 엽니다.
3. **학습팩 만들기**를 누르고 화면 안내를 따라 진행합니다.

앱에서 프롬프트 준비 → ChatGPT에서 문제 JSON 받기 → 앱에 가져와 공부하기.

Windows 10/11 64비트(x64)용입니다. 문제를 만드는 단계에서는 ChatGPT를 사용하며, 저장한 문제는 인터넷 없이 풀 수 있습니다.
