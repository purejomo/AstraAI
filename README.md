# AstraAI · 나의 학습실

내 자료로 학습팩을 만들고, 개념 학습·퀴즈·오답 복습을 이어가는 개인 학습 앱입니다. 운영자는 학습 자료를 등록하고, 학습자는 자신의 목표와 풀이 기록을 관리합니다.

**현재 제공 버전은 개인 PC에 설치해 사용하는 방식입니다.** 계정 선택은 체험용이며 실제 로그인이 아닙니다. 인터넷에서 여러 사람이 접속하는 운영 방식은 아직 지원하지 않습니다.

## 할 수 있는 일

- **학습 자료 등록**: ChatGPT에 사용할 프롬프트 만들기, JSON 파일 검사·미리보기·게시
- **개념 학습**: 요약, 핵심 내용, 자주 묻는 질문 읽기
- **문제 풀이**: 범위·문항 수 선택, 힌트, 채점과 해설
- **반복 학습**: 오답 노트, 복습 일정, 플래시카드, 시간 제한 모의고사
- **내 공부 관리**: 시험 목표, 하루 공부 시간, 학습 계획과 성취 기록

## 설치하고 시작하기

Git과 Node.js 22 이상을 준비하세요. 현재 실행 가능한 코드는 `feat/cloud-study-mvp` 브랜치에 있습니다. 저장소가 비공개이므로 다운로드하려면 접근 권한이 필요합니다.

Windows PowerShell에서 한 줄씩 실행하세요.

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\source" | Out-Null
Set-Location "$env:USERPROFILE\source"
git clone --branch feat/cloud-study-mvp https://github.com/purejomo/AstraAI.git
Set-Location AstraAI
npm.cmd ci
npm.cmd run build
npm.cmd start
```

`Ready`가 표시되면 같은 PC의 브라우저 주소창에 `http://localhost:3000`을 입력하세요. 사용하는 동안 터미널을 열어두고, 종료할 때는 `Ctrl+C`를 누릅니다. 다음에는 같은 폴더에서 `npm.cmd start`만 실행하면 됩니다.

이미 설치했다면 다시 복제하지 않아도 됩니다. 기존 `AstraAI` 폴더에서 `npm.cmd ci` → `npm.cmd run build` → `npm.cmd start`를 실행하세요. Windows의 `npm.ps1` 실행 정책 오류는 위와 같이 `npm.cmd`를 사용하면 해결할 수 있습니다.

macOS/Linux 설치, 업데이트, 백업 및 오류 해결은 [설치·사용 안내](docs/INSTALLATION.md)를 참고하세요.

## 첫 학습팩 사용하기

1. **관리자**로 입장하고 **샘플 불러오기**를 누릅니다.
2. **검증하고 미리보기**에서 내용을 확인하고 검수 항목을 체크합니다.
3. **검수한 초안 저장**을 누른 뒤 아래 목록에서 공유할 학습자를 선택하고 **게시**합니다.
4. 상단 계정을 **학습자 1**로 바꾸고 학습팩을 엽니다.
5. **개념 학습**을 읽고 **문제 풀기 → 퀴즈 시작**으로 진행합니다.
6. 틀린 문제는 **오답과 복습**에서 해설을 읽고 다시 풀어봅니다.

이 화면의 **게시**는 설치된 앱 안에서 학습팩을 보여주는 기능입니다. 인터넷에 사이트를 만드는 기능은 아닙니다.

## 내 자료로 학습팩 만들기

1. 관리자 화면에서 제목·학습 목표·문항 수를 입력하고 프롬프트를 복사합니다.
2. 본인의 ChatGPT 대화에 프롬프트와 원본 PDF·이미지를 직접 첨부합니다.
3. 받은 `study-pack.json`을 앱에 가져옵니다. UTF-8 JSON, 최대 5MB·500문항을 지원합니다.
4. 정답·해설·출처를 직접 검수하고 게시합니다.

앱이 ChatGPT로 자료를 자동 전송하거나 유료 AI API를 호출하지 않습니다. 샘플 또는 직접 작성한 JSON으로도 사용할 수 있으며, ChatGPT를 이용한다면 해당 서비스의 이용 조건이 적용됩니다. 생성된 문제의 정확성은 운영자가 확인해야 합니다.

[학습팩 형식](docs/DATA_CONTRACT.md) · [생성 프롬프트](prompts/GENERATE_STUDY_PACK.md) · [예제 JSON](examples/sample-study-pack.json)

## 다른 사람도 자기 학습실을 운영할 수 있나요?

코드에 접근할 수 있는 사람은 각자 내려받아 자신의 PC에 설치하고 **자기 설치본의 관리자**로 사용할 수 있습니다. 학습팩과 기록은 설치본마다 따로 저장되며, 원래 운영자의 자료나 계정을 공유하지 않습니다.

[독립 설치·코드 공유 안내](docs/SELF_HOSTING.md)에서 다른 사람에게 코드를 전달하는 방법과 데이터 분리 방식을 확인하세요.

## 무료로 온라인에서 사용할 수 있나요?

개인·비상업용 소규모 운영에는 **Vercel Hobby + Supabase Free**의 무료 한도를 이용하는 방법이 있습니다. 직접 상시 서버를 켜둘 필요 없이 웹 주소로 접속하는 구성입니다. 사용량 제한과 휴면 정책이 있으며 무제한 무료는 아닙니다.

현재 설치본을 그대로 올리는 방식은 지원하지 않습니다. 온라인용 로그인·권한·공유 저장소를 갖춘 버전이 필요합니다. 현재 무료 조건과 준비 사항은 [온라인 운영 안내](docs/HOSTING.md)에 정리했습니다.

## 기록 보관

학습팩과 기록은 설치 폴더의 `.local/study.json`에 저장됩니다. 새로고침이나 앱 재실행 후에도 유지되지만, 이 파일을 삭제하면 기록도 사라집니다. 앱을 종료한 상태에서 `.local` 폴더를 별도로 백업하세요. 실제 계정 인증이 없는 현재 설치본은 본인 PC에서 사용하세요.
