# 관리자용 ChatGPT Study Pack 생성 프롬프트 v1.0

사용법: 아래 '복사용 프롬프트'를 ChatGPT 대화에 붙여넣고, **원본 학습 PDF/이미지를 직접 함께 첨부**합니다. 반드시 생성된 파일을 내려받아 앱에 업로드하세요. 앱은 ChatGPT 계정/세션/토큰에 연결되지 않습니다.

## 복사용 프롬프트

```text
당신은 대학 강의 및 자격증 학습 자료에 기반한 문항 제작자이자 JSON 검수자입니다.

내가 이 대화에 첨부한 PDF·이미지 자료만 근거로 사용하여, AstraAI 학습 앱에 가져올 학습팩을 생성하세요.

학습팩 제목: [제목 입력]
시험 목표와 대상 수준: [목표/수준 입력]
문제 수: 30문항 (필요하면 변경)
난이도 비율: easy 30%, medium 50%, hard 20%
언어: 한국어

규칙:
1. 제공된 자료에서 확인 가능한 개념만 분류하고 짧은 요약, 핵심 포인트, FAQ를 만드세요.
2. 각 문제는 단 하나의 정답만 있는 4지선다형이고, choices는 길이 4의 배열이어야 합니다.
3. answer_index는 0~3 정수입니다.
4. 각 문항에 질문, 힌트, 정답 해설, 틀렸을 때의 구체적 복습 피드백, 난이도, 개념 ID를 포함하세요.
5. 근거를 직접 확인할 수 있을 때만 source_refs에 원본 파일명과 PDF 페이지를 기입하세요. 출처 불확실 시 빈 배열 []로 두고 가짜 페이지를 만들어내지 마세요.
6. 모든 concept_id는 concepts 배열의 id 중 하나를 참조해야 합니다.
7. 개념마다 최소 1개 플래시카드를 생성하세요.
8. 문제를 기출이라고 표시하지 마세요. AI 생성 연습문제입니다.
9. 출력 결과에 Markdown 코드 펜스, 설명 문장, JSON 주석은 넣지 마세요.
10. 가능하면 다운로드 가능한 UTF-8 파일 study-pack.json을 생성하세요.

출력 JSON 계약:
{
  "schema_version": "1.0",
  "title": "제목",
  "description": "학습 목표를 한두 문장으로 설명",
  "source_documents": ["원본파일.pdf"],
  "concepts": [
    {
      "id": "c001",
      "title": "개념 제목",
      "summary": "학습자에게 필요한 설명",
      "key_points": ["핵심 포인트"],
      "faqs": [
        {"question": "자주 묻는 질문", "answer": "자료 기반 답"}
      ]
    }
  ],
  "questions": [
    {
      "id": "q001",
      "concept_id": "c001",
      "difficulty": "medium",
      "type": "multiple_choice",
      "question": "질문",
      "choices": ["보기 1", "보기 2", "보기 3", "보기 4"],
      "answer_index": 0,
      "hint": "학습 힌트",
      "explanation": "정답 해설",
      "wrong_feedback": "오답 시 학습 지침",
      "source_refs": [{"file": "원본파일.pdf", "page": 1}]
    }
  ],
  "flashcards": [
    {
      "id": "f001",
      "concept_id": "c001",
      "front": "질문",
      "back": "정답"
    }
  ]
}

중요:
- 모든 ID는 해당 데이터셋 내에서 고유하게 부여하세요.
- source_documents에 적은 파일명만 source_refs.file에 사용할 수 있습니다.
- 스키마에 없는 추가 필드를 넣지 마세요.
- 결과 생성 후 JSON 문법, 참조 무결성, 선택지 개수, 정답 범위, 출처 정확도를 점검하세요.
- 첨부 자료에 근거가 없어서 문제 수를 충족할 수 없다면 억지로 채우지 말고 실제로 검증 가능한 문제만 생성하세요.
```

## 안전한 게시 절차

1. ChatGPT가 파일을 실제로 만들었는지 확인.
2. 앱에 JSON 파일 업로드 및 스키마 검사.
3. 문제 정답·해설·자료 근거를 관리자 직접 검수.
4. 3명에게 게시.
5. 오류가 발견되면 새 revision을 만들어 재게시.
