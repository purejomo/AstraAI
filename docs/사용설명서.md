# AstraAI 사용 설명서

## 설치하고 실행하기

1. [AstraAI-Setup.exe](https://github.com/purejomo/AstraAI/raw/refs/heads/main/AstraAI-Setup.exe)를 내려받습니다. 저장소 전체를 받을 필요는 없습니다.
2. 파일을 실행하고 비상업적 이용 조건을 확인한 뒤 설치 안내를 따릅니다.
3. 바탕화면이나 시작 메뉴의 **AstraAI**를 엽니다.

Windows 10/11 64비트(x64)를 지원합니다. 설치 파일에 실행에 필요한 프로그램이 포함되어 있습니다. 앱 사용에는 GitHub 계정, 터미널, 별도 서버가 필요하지 않습니다.

초기 설치 파일에는 코드 서명이 없어 Windows에서 ‘알 수 없는 게시자’나 SmartScreen 확인 화면이 나올 수 있습니다. 이 저장소에서 받은 파일인지 확인하세요.

## 처음 공부해 보기

1. **나의 문제은행 → 샘플로 시작하기**를 누릅니다.
2. 내용을 살펴보고 **내용과 정답을 확인했습니다**에 체크합니다.
3. **내 학습팩에 저장 → 바로 학습하기**를 누릅니다.
4. **문제 풀기 → 퀴즈 시작**에서 문제를 풀고 답안을 제출합니다.
5. 채점과 해설을 확인합니다. 틀린 문제는 **오답과 복습**에서 다시 풀 수 있습니다.

## 내 문제 만들기

**나의 문제은행 → 새 학습팩 만들기**에서 작성합니다.

1. 제목·설명과 공부할 개념의 제목·요약·핵심 내용을 입력합니다.
2. 문제와 보기 4개를 작성하고 정답을 하나 선택합니다.
3. 힌트·정답 해설·오답 복습 안내를 적습니다. **문제 추가**로 문항을 늘릴 수 있습니다.
4. 필요하면 개념과 플래시카드를 더 추가합니다.
5. **검증하고 미리보기**에서 내용을 확인한 뒤 저장합니다.

개념과 문제는 각각 하나 이상 필요합니다. 빈 필수 항목이나 잘못된 정답 등이 있으면 수정할 위치를 안내합니다. 저장한 문제는 **내가 만든 학습팩 → 수정하기**에서 고칠 수 있습니다.

## 문제 파일 가져오기·공유하기

- **JSON 파일로 가져오기**: 받은 문제 파일을 선택하고, 내용을 검수한 뒤 저장합니다. UTF-8 JSON, 최대 5MB·500문항을 지원합니다.
- **JSON 내보내기**: 저장한 학습팩을 파일로 내려받습니다. 다른 사람도 자기 앱에서 가져와 공부할 수 있습니다. 개인 풀이 기록은 포함되지 않습니다.
- **ChatGPT에 사용할 프롬프트 만들기**: 원한다면 앱에서 준비한 프롬프트와 본인의 자료를 ChatGPT에 첨부하고, 받은 JSON을 가져올 수 있습니다. 문제와 정답은 직접 확인하세요. 직접 작성할 때는 ChatGPT가 필요하지 않습니다.

공식 원본 `AstraAI-Setup.exe`는 비상업적 이용을 위해 무료로 전달할 수 있습니다. 받은 사람은 GitHub 로그인 없이 설치하고 사용할 수 있습니다. 각자의 문제와 기록은 각자의 PC에 저장됩니다.

## 다른 학습 기능

- **나의 학습팩**: 개념 읽기, 퀴즈, 플래시카드, 시간 제한 모의고사
- **오답과 복습**: 틀린 문제와 복습할 카드 확인
- **학습 계획**: 시험일과 하루 공부 시간 설정
- **학습 현황**: 풀이 기록과 개념별 성취도 확인

## 백업과 업데이트

앱 상단 **AstraAI → 학습 데이터 폴더 열기**로 저장 위치를 엽니다. 기본 위치는 `%APPDATA%\AstraAI\data`입니다.

앱을 종료한 뒤 이 폴더를 다른 위치에 복사하면 저장한 문제와 학습 기록을 백업할 수 있습니다. 작성 중인 내용은 먼저 저장하거나 **작성 중 JSON 내려받기**로 따로 보관하세요.

업데이트할 때는 앱을 종료하고 새 `AstraAI-Setup.exe`를 실행합니다. 같은 Windows 계정으로 설치하면 기존 기록을 이어 사용합니다. 프로그램을 제거해도 학습 데이터는 자동 삭제하지 않습니다.

앱이 열리지 않으면 이미 실행 중인 창을 닫고 다시 실행하세요. 계속 실패하면 `%APPDATA%\AstraAI\desktop-error.log`에서 오류를 확인할 수 있습니다. 문제 해결을 위해 학습 기록 파일을 삭제할 필요는 없습니다.
