# AstraAI 사용 설명서

## 설치하고 실행하기

1. [AstraAI-Setup.exe](https://github.com/purejomo/AstraAI/raw/refs/heads/main/AstraAI-Setup.exe) 하나를 내려받습니다.
2. 실행하고 설치 안내를 따릅니다.
3. 바탕화면이나 시작 메뉴의 **AstraAI**를 엽니다.

Windows 10/11 64비트(x64)용입니다. GitHub 로그인이나 별도 프로그램 설치 없이 실행할 수 있습니다. 설치 파일에는 코드 서명이 없어 Windows 확인 화면이 나올 수 있습니다. 이 저장소에서 받은 파일인지 확인하세요.

## 문제를 만들어 공부하기

앱의 **학습팩 만들기**에서 한 단계씩 안내합니다.

1. **조건 입력** — 제목, 학습 목표와 수준, 문항 수를 입력합니다.
2. **프롬프트 복사** — **프롬프트 복사하고 다음**을 누릅니다.
3. **GPT에서 생성** — **ChatGPT 열기**를 누르고, 공부할 PDF·이미지와 복사한 프롬프트를 보냅니다. GPT가 만든 `study-pack.json` 파일을 내려받습니다.
4. **JSON 가져오기** — 앱으로 돌아와 **JSON 파일을 받았어요 → JSON 파일 선택**을 누릅니다.
5. **확인·저장** — 문제와 정답을 살펴보고 확인란에 체크한 뒤 **학습팩 저장 → 바로 학습하기**를 누릅니다.

JSON 형식에 오류가 있으면 앱에 표시된 오류를 ChatGPT에 전달하고 파일을 다시 만들어 달라고 요청하세요. 문제 내용이나 정답이 잘못된 경우에도 GPT에 수정을 요청한 뒤 새 파일을 가져오세요.

이미 문제 JSON을 받았다면 첫 화면의 **이미 JSON 파일이 있어요**로 바로 가져올 수 있습니다. 파일은 UTF-8 JSON, 최대 5MB·500문항을 지원합니다.

ChatGPT는 별도 브라우저에서 사용합니다. 자료를 보내거나 파일을 받는 단계는 사용자가 직접 진행하며, 앱에 AI API 키를 넣을 필요는 없습니다. 저장한 문제를 푸는 데는 인터넷이 필요하지 않습니다.

## 문제 풀기와 오답 복습

**나의 학습팩**에서 공부할 학습팩을 열고 **문제 풀기 → 퀴즈 시작**을 누릅니다. 답안을 제출하면 점수와 해설이 나옵니다. 틀린 문제는 **오답과 복습**에서 다시 풀 수 있습니다.

개념 학습, 플래시카드, 모의고사도 학습팩 안에서 이용합니다. **학습 계획**에서 공부 시간을 정하고 **학습 현황**에서 기록을 확인할 수 있습니다.

## 파일 보관과 업데이트

GPT에서 내려받은 JSON을 보관하면 다시 가져오거나 다른 사람에게 전달할 수 있습니다. 공식 원본 설치 파일도 비상업적 이용을 위해 무료로 전달할 수 있으며, 각자의 학습 기록은 각자의 PC에 저장됩니다.

학습 기록을 백업하려면 앱 상단 **AstraAI → 학습 데이터 폴더 열기**를 누른 뒤 앱을 종료하고 해당 폴더를 복사하세요. 기본 위치는 `%APPDATA%\AstraAI\data`입니다.

업데이트할 때는 앱을 종료하고 새 `AstraAI-Setup.exe`를 실행합니다. 같은 Windows 계정으로 설치하면 기존 기록을 이어 사용합니다. 프로그램을 제거해도 학습 데이터는 자동 삭제하지 않습니다.

앱이 열리지 않으면 실행 중인 창을 닫고 다시 실행하세요. 계속 실패하면 `%APPDATA%\AstraAI\desktop-error.log`에서 오류를 확인할 수 있습니다.
