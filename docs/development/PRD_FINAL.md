# AstraAI 최종 PRD (결정 버전 3.0)

확정일: 2026-11-07. 최신 사용자 요청에 따라 **개인 문제은행 제작과 학습**을 하나의 흐름으로 제공한다. 이전의 관리자 1명/학습자 3명·게시·초대 모델을 대체한다.

## 1. 제품 목표

저장소에 접근할 수 있는 누구나 자기 PC에 설치하고 스스로 개념·문제·해설·카드를 작성해 공부한다. 원래 운영자의 콘텐츠 업로드, 관리자 권한 발급, 다른 계정으로 전환하는 과정이 필요하지 않다. 분야는 고정하지 않으며 대학생·자격증 수험생의 개인 학습을 지원한다.

현재는 개인 PC용 단일 사용자 학습실이다. 다른 사람이 복제한 앱과 자료·기록은 독립적이다. PC와 모바일 화면에 대응하되 인터넷 접속, 실제 인증, 온라인 DB는 후속 범위다. 유료 AI/API 비용은 발생하지 않는다.

## 2. 콘텐츠 제작

1. 앱을 열면 학습 홈이 표시된다. 사용자가 선택할 로그인/관리자 프로필은 없다.
2. **나의 문제은행 → 새 학습팩 만들기**에서 제목·설명, 개념·요약·핵심 내용·FAQ, 4지선다 문제·난이도·정답·힌트·해설·오답 안내, 선택적 출처와 플래시카드를 작성한다.
3. 개념/문제/카드를 추가·수정·제거할 수 있다. 참조 중인 개념 삭제는 차단해 연결을 보존한다.
4. 기존 JSON 가져오기와 샘플 시작도 같은 편집기로 연결된다. ChatGPT 수동 프롬프트 준비는 선택 사항이다.
5. 서버 검증 → 미리보기 → 사용자의 내용 확인 → 저장. 저장한 학습팩은 곧바로 학습 가능하다.
6. 수정은 새 불변 revision으로 저장한다. 다른 탭의 새 저장본을 오래된 편집으로 덮어쓰지 않는다.
7. JSON 내보내기에는 최신 학습팩 내용만 포함한다. 다른 설치본에서 검증하고 새 학습팩으로 가져올 수 있다.
8. 작성 중 초안은 같은 브라우저/출처에 임시 보관한다. 정식 저장·학습 기록 백업과 구분하며 저장 실패를 숨기지 않는다.

문제를 직접 작성할 수 있으므로 ChatGPT 계정은 필수가 아니다. 앱이 PDF/이미지를 자동 분석하거나 실시간 AI를 호출하는 것으로 표현하지 않는다. 수동 생성 시 사용자가 본인의 ChatGPT에 원본 자료를 첨부하고 결과를 검수한다.

## 3. 학습 기능

- 개념 요약·핵심 내용·FAQ, 읽음 기록
- 범위·문항 수 선택, 4지선다 퀴즈, 힌트, 서버 채점 및 해설/출처
- 답안 복원과 중복 제출 방지, 새로고침 후 학습 이력 유지
- 오답 노트와 당시 버전의 재응시, 복습 일정
- 플래시카드 앞/뒷면, 기억 여부에 따른 복습
- 서버 발급 마감 시각을 사용하는 모의고사, 미응답 채점
- 시험 목표·하루 학습 시간·학습 계획, 최근 시도와 개념별 성취도
- 확인 문구 입력 후 현재 사용하는 기록 삭제. 학습팩과 다른 이전 기록은 보존

## 4. 규칙 기반 개인화

실시간 AI 판단이 아닌 결정적 학습 보조 규칙이다.

- 최근 최대 10번 시도로 개념 지표 계산. 3회 미만은 ‘판단 데이터 부족’.
- 정답률 60% 미만 ‘집중 복습’, 60~79% ‘학습 중’, 80% 이상 + 최근 2회 정답 ‘익숙함’.
- 오답은 다음날 복습. 이후 연속 정답은 3일 → 7일 → 14일. 다시 오답이면 1일로 초기화.
- 시험일·취약 개념·미학습 단원을 기반으로 학습량 제안. 서울 날짜 기준.
- 합격 가능성이나 실제 학습 능력의 진단·예측으로 표현하지 않음.

## 5. 데이터 및 호환성

JSON `schema_version=1.0` 계약을 유지한다. 개념과 문제 각각 최소 1개, 4개 보기와 단일 정답, 최대 5MB/500문항. 빈 내용, 중복 ID/보기, 없는 개념, 출처 파일명 불일치, 범위 밖 정답을 서버에서 거부한다. 원본 근거의 진위는 사용자가 확인한다.

기존 `.local/study.json`을 그대로 읽는다. 기본 기록은 이전 `learner-1`; 다른 데모 기록도 삭제하거나 합치지 않는다. 이전 기록이 있다면 설정에서 이어 쓸 이력을 선택한다. 기존 비공개 초안도 소유자의 문제은행에 표시한다. 기존 응시·복습은 원래 revision을 유지하며 새 버전의 개념 진도/성취도는 따로 쌓는다.

## 6. 디자인과 접근성

기존 Taste Skill의 타이포그래피·여백·일관된 정렬·대비·명확한 행동 문구를 적용한다. 따뜻한 밝은 배경과 절제된 녹색. 장식용 AI 채팅, 가짜 실시간 응답을 추가하지 않는다. 모든 입력의 라벨과 키보드 포커스를 제공하고 1440/1024/768/390px에서 사용 가능하게 한다. 모바일에서도 정답 선택과 긴 문제 입력이 잘리지 않아야 한다.

## 7. 수용 기준

1. 새 설치에서 운영자나 계정 전환 없이 문제를 만들고 즉시 공부할 수 있다.
2. 직접 작성·JSON 가져오기 모두 같은 검증/검수 절차를 통과한다.
3. 오류가 있는 편집은 저장본에 영향을 주지 않는다. 수정 충돌은 명시적으로 안내한다.
4. 개념→풀이→채점→오답→복습→카드→모의고사→목표/현황이 동작한다.
5. 편집 후 과거 정답/해설/기록이 보존된다.
6. JSON 내보내기/다른 설치본 가져오기가 내용과 참조를 유지한다.
7. 로컬 Host·동일 Origin·세션 검사를 유지한다. 작성자가 자신의 정답을 편집하는 것은 허용하되 출제 DTO에는 정답을 포함하지 않는다.
8. 새로고침/재실행 후 저장 내용이 유지되며 기존 자료를 자동 삭제하지 않는다.
9. 유료 AI API·외부 배포 없이 실행하고 테스트한다.
10. 사용자용 README와 개발 문서를 분리하며 미지원 온라인 기능을 명시한다.

## 8. 후속 범위

실제 로그인·사용자별 온라인 문제은행·DB·무료 호스팅은 [온라인 전환 계획](ONLINE_ROADMAP.md)을 따른다. PWA·음성 읽기 등도 후속이다. 저장소 공개 범위·라이선스·외부 배포·계정 연결은 별도 결정이며 현재 작업에서 변경하지 않는다.

## 9. Windows 설치 파일 요구 (2026-11-07 추가)

- 사용자는 `.exe`를 설치해 전용 앱 창에서 학습하며 Git·Node.js·GitHub 로그인 없이 실행할 수 있다.
- 앱 실행 환경과 문제 작성·채점·저장 기능을 함께 묶고 인터넷 없는 상태의 개인 학습을 지원한다.
- 사용자 데이터와 프로그램 파일을 분리하고 업데이트/제거 시 학습 기록을 자동 삭제하지 않는다.
- Windows에서 설치 파일 생성·실제 설치·설치본 실행·학습·종료·재시작 후 기록 유지까지 검증한다.
- 비공개 저장소의 릴리즈 다운로드와 앱 실행 조건을 구분한다. 로그인 없는 공개 다운로드 위치는 별도 승인 사항이며 자동 게시하지 않는다.
