# 내 문제은행 만들기

AstraAI를 실행하면 바로 나의 학습실이 열립니다. 같은 사람이 문제를 만들고 공부할 수 있으며, 관리자에게 자료 등록을 요청할 필요가 없습니다.

[PC 작성 화면](screenshots/editor-desktop.png) · [모바일 작성 화면](screenshots/editor-mobile.png)

## 화면에서 직접 작성하기

1. 왼쪽 메뉴 **나의 문제은행 → 새 학습팩 만들기**를 엽니다. 모바일에서는 상단 메뉴 버튼으로 이동합니다.
2. 학습팩 제목과 설명을 적습니다.
3. 개념 제목·요약·핵심 내용을 입력합니다. 핵심 내용은 한 줄에 하나씩 적고, 필요하면 개념과 자주 묻는 질문을 추가합니다.
4. 문제마다 개념과 난이도를 선택하고 질문·서로 다른 보기 4개를 작성합니다. 맞는 보기 옆의 **정답**을 하나 선택하세요. 처음에는 1번이 선택되어 있으니 실제 정답을 꼭 확인하세요.
5. 정답 해설·힌트·오답 복습 안내를 적습니다. **문제 추가**로 늘리고 **편집할 문제** 목록으로 이동합니다.
6. 필요하면 플래시카드 앞면·뒷면을 추가합니다.
7. **검증하고 미리보기**에서 정답과 해설을 검수하고 확인란을 체크한 뒤 **내 학습팩에 저장**을 누릅니다.
8. **바로 학습하기**로 이동해 개념·퀴즈·플래시카드·모의고사를 이용합니다.

개념과 문제는 각각 하나 이상 필요합니다. 문제는 학습팩당 최대 500개이며 전체 JSON은 5MB 이하입니다. 빈 필수 항목, 중복 보기, 없는 개념 연결, 잘못된 정답 등은 저장 전에 오류로 안내됩니다. 문제 내용의 정확성은 직접 확인해야 합니다.

## 출처 남기기

문제의 **자료 출처**를 펼쳐 원본 파일 이름을 한 줄에 하나씩 등록합니다. **출처 추가**에서 해당 문제의 파일명과 확인된 페이지를 적습니다. 출처의 파일명은 등록한 이름과 일치해야 합니다. 페이지가 없는 자료는 페이지를 비워둘 수 있습니다.

파일 자체는 앱에 업로드되지 않습니다. 근거를 확인하지 못했다면 출처를 추가하지 마세요. 학습할 때 ‘출처 미확인’으로 표시됩니다.

## 샘플 또는 JSON에서 시작하기

- **샘플로 시작하기**: 운영체제 예제를 편집 화면에 불러옵니다. 검수 후 저장하면 바로 학습할 수 있습니다.
- **JSON 파일로 가져오기**: UTF-8 `study-pack.json` 파일을 선택하거나 내용을 붙여 넣습니다. 검증을 통과하면 편집 화면에서 직접 수정할 수 있습니다.
- **ChatGPT에 사용할 프롬프트 만들기**: 제목·목표·문항 수를 입력해 복사합니다. 본인의 ChatGPT에 원본 자료와 함께 수동으로 첨부하고 받은 JSON을 가져옵니다. 앱의 자동 생성이나 유료 AI API 연결은 없습니다.

가져온 파일은 **새 학습팩**으로 저장됩니다. 기존 학습팩의 수정은 아래의 **수정하기**를 사용하세요.

## 수정과 버전 보관

**내가 만든 학습팩 → 수정하기**에서 개념·문제·카드를 수정하고 같은 검수 절차로 저장합니다. 새 버전으로 학습을 시작할 수 있고, 이미 풀었거나 복습 중인 문제는 당시 버전의 정답·해설을 유지합니다. 개념 학습 완료와 현재 버전의 성취 지표는 새 버전에서 다시 쌓습니다. 전체 풀이 이력은 유지됩니다.

문제나 카드가 연결된 개념은 바로 삭제할 수 없습니다. 해당 항목을 다른 개념으로 옮기거나 편집본에서 제거한 뒤 개념을 삭제하세요. 저장하기 전의 편집만 바뀌며 이전 기록은 보존됩니다.

다른 탭에서 먼저 저장한 수정본이 있으면 덮어쓰기가 차단됩니다. **작성 중 JSON 내려받기**로 작업을 보관한 뒤 최신 학습팩을 열어 변경 내용을 반영하세요.

## JSON 내보내기와 기록 백업

- **JSON 내보내기**: 저장된 최신 학습팩의 개념·문제·정답·해설·카드를 내려받습니다. 다른 설치본에서 그대로 가져올 수 있습니다. 개인 풀이·복습·계획·세션은 포함되지 않습니다.
- **작성 중 JSON 내려받기**: 아직 완성하지 않은 내용도 파일로 보관합니다. 필수 항목이 비어 있다면 가져오기 전에 파일을 완성해야 합니다.
- 작성 중 내용은 **같은 브라우저·같은 주소**에 임시 보관됩니다. 새로고침 후 문제은행을 열면 이어서 편집할 수 있습니다. 브라우저 저장 공간이 부족하면 오류가 표시되므로 JSON을 내려받으세요.
- 정식 저장한 학습팩과 학습 기록 전체는 앱을 종료하고 `.local` 폴더를 복사해 백업합니다. 자세한 방법은 [설치 안내](INSTALLATION.md#저장-위치와-백업)를 참고하세요.

소스 코드나 학습팩 JSON만 다른 사람에게 전달하면 각자의 문제은행과 학습 기록을 독립적으로 사용할 수 있습니다.
