# AstraAI 최종 PRD (결정 버전 2.0)

확정일: 2026-11-07  
상태: 제품/데이터 설계 확정, 배포/개발 완료 아님  
제품 성격: 개인 학습용, 유료 서비스나 상업적 수익화 계획 없음

## 1. 제품 목표

ChatGPT Pro를 사용하는 관리자 1명이 PDF 또는 이미지 학습 자료를 바탕으로 **학습팩(JSON)**을 수동 제작하여 세 명의 가족·지인에게 공유합니다. 학습자는 ChatGPT 계정, 토큰, API 호출 없이 별도 PC에서 로그인해 문제 풀이, 개념 정리, 플래시카드, 모의고사, 학습 계획 및 오답 복습을 이용합니다.

### 의사결정 / 제약

- 대상: 대학생과 자격증 수험생, **분야는 미정/비고정**
- 이용자: **학습자 3명 + 콘텐츠 제작 관리자 1명**
- 디바이스: 각자 다른 PC에서 인터넷 접속, 모바일 화면 대응, iOS/Android 네이티브 앱은 후속
- UI: 집중을 돕는 차분한 타이포그래피와 정보 구조, Astra에서 영감을 받은 학습 흐름, 독자적 구현
- 입력 소스: PDF 및 JPG/PNG/WebP 이미지(단, ChatGPT에 직접 첨부하는 수동 경로)
- AI 실행: 앱 내부에는 **실시간 생성형 AI 호출 없음**
- 문제은행: 관리자가 자신의 ChatGPT Pro에서 학습용 JSON 파일을 만들어 업로드·공유
- 개인화: 학습 기록에 기반한 **결정적 규칙 엔진**, 'AI가 실시간 분석했다'고 표시하지 않음
- 추가 비용: AI/API 0원, 무료 웹/DB 한도 내 운영(호스팅 서비스 한도·휴면 가능성 있음)
- 진행 원칙: 기능 우선, 오늘 목표는 핵심 학습 루프 검증. 전체 Astra 기능 동등성을 하루 내 보장하지 않음.

## 2. 사용자 권한

| 역할 | 권한 |
|---|---|
| 관리자(owner) | 학습팩 만들기 절차 안내/프롬프트 생성/JSON 검증/미리보기/수정본 교체/게시/공유 대상 지정/사용자 초대 및 취소/기본 통계 |
| 학습자(learner) | 공개된 학습팩·개념 학습·퀴즈·모의고사·플래시카드·힌트·해설·오답 복습·자신의 학습 계획/기록 |
| 익명 방문자 | 로그인 화면만 이용, 콘텐츠 열람 불가 |

초대는 3명 한도(관리자 제외). 공개 가입/링크 공개는 금지. 초대 코드 만료·1회 소비. 개인 학습 데이터는 관리자에게 필요 최소한의 운영 상태만 제공하고, 타 학습자에게 노출하지 않습니다.

## 3. 가장 중요한 사용자 플로우

### 3.1 학습팩 제작 (관리자)

1. 로그인 → 관리 콘솔 → 새 학습팩.
2. 제목/학습 분야/학습 목적/원하는 문항 수(기본 30)/난이도 분포를 입력하고 원본 PDF/이미지를 선택합니다.
3. 앱이 정해진 JSON 계약을 포함한 **프롬프트를 만듭니다.**
4. '프롬프트 복사' → ChatGPT 이동 → **관리자가 같은 원본 자료를 ChatGPT에도 수동 첨부** → 문제/개념/해설/플래시카드 생성.
5. ChatGPT에서 `study-pack.json` 내려받기 → 앱 'JSON 가져오기'.
6. 앱이 파일 크기, UTF-8, JSON 문법, JSON Schema, 참조 무결성, 정답 범위, 선택지 중복 여부를 검사합니다.
7. 관리자가 검수 미리보기 → '3명에게 공개' → 새 revision 저장.
8. 학습자는 공개된 학습팩만 봅니다. 이미 응시한 문제는 revision이 바뀌어도 과거 기록과 연결해 보관합니다.

### 3.2 학습자 일상 플로우

1. 초대 링크로 가입 또는 로그인 → 내 학습팩.
2. 학습 목표/시험 날짜/하루 공부 가능 시간을 입력.
3. '오늘 할 일'에서 개념 1개 학습 → 문제 5~10개 풀기.
4. 제출 후 채점, 설명, 출처(있는 경우), 틀린 선택지에 대한 피드백 확인.
5. 오답은 다음 복습 일정으로 자동 등록, 정답 기록도 별도 누적.
6. 개념별 정답률/풀이 수/취약 목록/남은 일정 표시.
7. 복습 → 재응시 → 반복. 계정별 학습 데이터는 분리.

## 6. 규칙 기반 개인화 (AI가 아님)

- 문항 단위: 정답/오답 및 누적 시도를 저장. 여러 번 재응시 가능.
- 개념 단위: 최근 최대 10번 시도의 정답 비율을 집계. **시도 3회 미만은 '판단 데이터 부족'**.
- 최근 정답률 60% 미만: '집중 복습', 60~79%: '학습 중', 80% 이상 + 최근 2회 정답: '익숙함'.
- 오답한 문항: 다음날 복습. 그 이후 연속 정답 1회 → 3일, 2회 → 7일, 3회 이상 → 14일. 다시 오답이면 1일로 초기화.
- 시험일 D-day: 취약 개념과 미학습 단원 우선 배정. 시험일 미정은 단원 순서 기반.
- 출력: '최근 10문항 중 6개 정답, 3개념 취약'처럼 근거가 있는 문구만 사용.
- 위 수치는 학습 보조용 제품 규칙이며 실제 학습 능력이나 합격 가능성의 진단·예측이 아닙니다.

## 7. JSON 입력/품질 정책

- 표준 형식: [study-pack.schema.json](../schemas/study-pack.schema.json) (`schema_version=1.0`).
- 문항당 4지선다, 정답 1개, 정답 인덱스 0~3, 난이도, 개념 ID, 해설, 힌트, 오답 설명, 출처.
- 개념별 요약과 플래시카드, 미리 작성된 FAQ를 포함하여 정적 튜터 화면 구성.
- 중복 ID, 존재하지 않는 concept_id, 범위 밖 정답, 중복 보기, 파손 JSON, 과대 파일을 거부.
- 원본 파일의 페이지/인용 근거가 불확실하면 `source_refs: []` 허용하고 '출처 미확인' 표기. 페이지를 꾸며내지 않습니다.
- 생성 결과가 틀릴 수 있으므로 관리자가 게시 전 문제 정답과 출처를 직접 검수해야 합니다.
- JSON 공유는 관리자만. 원본 PDF/이미지 자체 공유는 기본 OFF, 저장이 필요하면 별도 비공개 권한 적용.

## 8. 시각적 방향

- 정보의 위계가 분명한 차분한 학습 도구. 짙은 글자, 따뜻한 밝은 바탕, 절제된 녹회색 포인트.
- 예시 디자인 토큰: background `#F8F8F4`, surface `#FFFFFF`, ink `#202723`, muted `#69736C`, accent `#4F745E`, border `#E1E6E0`.
- 실제 학습 콘텐츠 중심: 불필요한 그라데이션, 번쩍이는 효과, 가짜 AI 채팅 애니메이션 금지.
- 버튼/카드/목록/진도/문항 스테퍼는 일관된 디자인 시스템. Taste Skill의 타이포그래피/간격/그리드/브라우저 검수 원칙을 참고하되 구성 요소는 직접 구현.
- Astra 브랜드, 상표, 고유 일러스트와 픽셀 단위 레이아웃을 그대로 재사용하지 않음.

## 9. 출시 게이트

1. 관리자만 JSON 업로드/게시 가능.
2. 3명의 로그인과 학습 기록이 서로 교차 조회되지 않음.
3. 잘못된 JSON 10종에 대해 명시적 오류와 안전한 실패.
4. 정상 JSON을 게시해 다른 브라우저 계정에서 즉시 학습 가능.
5. 풀이 → 채점 → 오답 → 복습 → 결과까지 새로고침 후에도 유지.
6. 비용이 발생하는 모델 API 호출이 앱 코드에 없음.
7. 390px 모바일 뷰에서 수평 스크롤/겹침이 없음.
8. PDF 업로드가 자동 ChatGPT 전송으로 오인되지 않음.
9. Free-tier 한도, 휴면 정책, 보안 설정을 README에서 확인할 수 있음.
10. 미완성 기능은 '개발 예정'으로 분리하고 실제 작동하는 것처럼 표시하지 않음.
