# Windows 앱 사용하기

Windows용 `AstraAI-Setup-0.2.0-x64.exe`에 앱과 실행 환경이 함께 들어 있습니다. **실행하는 사람은 Git·Node.js를 설치하거나 GitHub에 로그인할 필요가 없습니다.** 설치 후 문제 만들기·풀이·복습은 인터넷 연결 없이 사용할 수 있습니다. ChatGPT를 별도로 이용할 때만 해당 서비스의 연결과 계정이 필요합니다.

현재 공개 다운로드 페이지는 아직 게시하지 않았습니다. 설치 파일을 전달받아 사용하는 방식이며, 파일 이름과 함께 제공되는 `SHA256SUMS.txt`를 확인하세요.

## 설치와 시작

1. Windows x64용 `AstraAI-Setup-0.2.0-x64.exe`를 실행합니다.
2. 설치 안내를 따라 현재 Windows 사용자 계정에 설치합니다.
3. 바탕화면 또는 시작 메뉴의 **AstraAI**를 엽니다.
4. **나의 문제은행 → 새 학습팩 만들기** 또는 **샘플로 시작하기**를 선택합니다.

명령어를 입력하거나 터미널을 켜둘 필요가 없습니다. 앱 창을 닫으면 앱의 저장·채점 프로세스도 종료됩니다. 두 번 실행해도 같은 학습실 창으로 돌아옵니다. 64비트 Windows용이며 macOS·Linux 설치 파일은 제공하지 않습니다.

초기 설치 파일에는 디지털 코드 서명이 없습니다. Windows에서 알 수 없는 게시자 또는 SmartScreen 확인 화면이 나타날 수 있습니다. 파일을 제공한 사람과 다운로드 출처를 확인하세요. 해시는 PowerShell에서 다음과 같이 확인할 수 있습니다.

```powershell
Get-FileHash .\AstraAI-Setup-0.2.0-x64.exe -Algorithm SHA256
```

표시된 값이 같은 경로로 받은 `SHA256SUMS.txt`의 값과 일치하는지 확인합니다. 코드 서명이나 유료 인증서 비용은 추가하지 않았습니다.

## 내 문제은행과 기록

학습 내용은 각 사용자의 PC에만 저장됩니다. 파일 위치는 앱 상단 **AstraAI → 학습 데이터 폴더 열기**에서 확인할 수 있습니다.

기본 위치:

```text
%APPDATA%\AstraAI\data\study.json
```

앱을 종료한 뒤 `data` 폴더를 복사하면 저장된 학습팩·풀이·복습·계획을 백업할 수 있습니다. 작성 중인 초안은 앱의 별도 임시 보관 영역에 있으므로 정식 저장하거나 **작성 중 JSON 내려받기**로 보관하세요. 앱을 업데이트하거나 제거해도 학습 데이터 폴더를 자동 삭제하지 않습니다.

다른 사람에게 문제만 전달하려면 **JSON 내보내기**를 사용하세요. 받은 사람은 자기 앱에서 **JSON 파일로 가져오기**로 등록합니다. 자세한 방법은 [문제은행 안내](QUESTION_BANK.md)에 있습니다.

## 기존 소스 실행 버전의 자료 가져오기

학습팩만 옮기려면 기존 앱에서 JSON으로 내보내고 Windows 앱에서 가져오세요.

학습 기록도 모두 옮기려면:

1. 기존 앱과 Windows 앱을 모두 종료합니다.
2. 기존 저장소의 `.local/study.json`을 별도로 백업합니다.
3. Windows 앱에 이미 기록이 있다면 `%APPDATA%\AstraAI\data\study.json`도 별도로 백업합니다.
4. 기존 파일을 Windows 앱의 `data` 폴더에 `study.json`이라는 이름으로 복사하고 앱을 다시 엽니다.

이 과정은 두 기록을 합치는 기능이 아니라 사용할 기록 파일을 선택하는 방식입니다. 브라우저에만 남아 있는 미저장 초안은 먼저 정식 저장하거나 JSON으로 내려받으세요.

## 업데이트

앱을 종료하고 데이터를 백업한 뒤 새 버전의 설치 파일을 실행합니다. 같은 Windows 사용자 계정으로 실행하면 이전 학습 기록을 이어 씁니다. 자동 업데이트나 외부 서버 연결은 없습니다.

## GitHub 로그인과 파일 공유

- **앱 실행**: GitHub 계정이나 로그인이 필요하지 않습니다.
- **설치 파일 직접 전달**: 받은 사람도 로그인 없이 설치하고 사용할 수 있습니다.
- **비공개 GitHub 저장소에서 다운로드**: 저장소 접근 권한과 로그인이 필요합니다. 릴리즈에 올린 파일도 같은 제한을 받습니다.
- **로그인 없는 공개 다운로드**: 공개된 배포 위치가 필요합니다. 소스는 비공개로 두고 설치 파일만 별도의 공개 배포 저장소에 둘 수 있습니다. 현재 공개 배포나 저장소 공개 전환은 수행하지 않았습니다.

## 시작되지 않는 경우

- 앱 전용 포트가 사용 중이라는 안내가 나오면 실행 중인 AstraAI 창을 닫고 다시 실행하세요. 다른 프로그램이 같은 포트를 사용한다면 충돌을 해결한 뒤 실행합니다. 앱이 다른 프로그램의 화면에 잘못 연결되지 않도록 확인합니다.
- 문제가 계속되면 `%APPDATA%\AstraAI\desktop-error.log`에서 오류 설명을 확인할 수 있습니다.
- 기록을 초기화하려고 `study.json`을 삭제하지 마세요. 먼저 별도로 백업하고 정상 파일로 복원하세요.
