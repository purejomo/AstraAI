# 다른 사람의 독립 설치와 코드 공유

AstraAI 코드를 받은 사람은 자신의 PC에 따로 설치해 **자기 문제은행을 만들고 바로 학습**할 수 있습니다. 원래 운영자의 업로드나 계정 발급을 기다릴 필요가 없습니다.

## 독립 설치하면 무엇이 달라지나요?

| 항목          | 독립 설치 시                                 |
| ------------- | -------------------------------------------- |
| 프로그램 코드 | 같은 버전을 사용하고 필요할 때 각자 업데이트 |
| 학습팩        | 직접 작성·수정하거나 JSON으로 가져오기       |
| 학습 기록     | 각 설치본의 저장 폴더에 따로 보관            |
| 사용 방식     | 계정 전환 없이 작성부터 학습까지 이용        |
| 접속 주소     | 각자의 PC에서 `http://localhost:3000` 사용   |
| 서버 비용     | 개인 PC 설치에는 별도 호스팅 이용료 없음     |

현재 버전은 본인 PC에서 사용하는 개인 학습실이며 인터넷용 로그인을 제공하지 않습니다. 여러 사람이 링크로 접속하는 운영은 [온라인 운영 안내](HOSTING.md)를 참고하세요.

## 코드를 전달하는 방법

현재 `purejomo/AstraAI`는 **비공개 저장소**입니다. 저장소 링크를 받았다는 이유만으로 누구나 다운로드할 수 있지는 않습니다.

- 접근 권한을 받은 사람은 Git으로 복제하거나 GitHub의 **Code → Download ZIP**으로 받을 수 있습니다.
- GitHub에서 현재 앱이 있는 **`feat/cloud-study-mvp` 브랜치**를 선택한 뒤 다운로드하세요.
- ZIP으로 받으면 압축을 푼 폴더에서 [설치 안내](INSTALLATION.md)의 의존성 설치 → 빌드 → 실행 순서로 진행합니다. Git 저장소가 아니므로 `git pull` 대신 새 ZIP을 받아 업데이트해야 합니다. 기존 `.local` 기록은 먼저 백업하세요.
- Git으로 받으면 `git pull --ff-only`로 같은 브랜치의 변경을 받을 수 있습니다.

누구나 내려받을 수 있게 하려면 소유자가 저장소 공개 범위와 사용·수정·재배포 조건을 정해야 합니다. 현재 저장소에는 LICENSE 파일이 없습니다. 다운로드 가능 여부와 재배포 허용 범위는 별개의 사항이며, 저장소를 공개하는 것만으로 오픈소스 라이선스가 자동으로 생기지는 않습니다. 이 안내를 추가하면서 저장소 공개 설정이나 라이선스를 변경하지는 않았습니다.

## 전달할 때 제외할 자료

프로그램은 GitHub의 소스 코드로 전달하고, 실제 사용 중인 설치 폴더 전체를 압축해 전달하지 않는 것이 좋습니다. 특히 다음 항목은 개인 자료입니다.

- `.local/` 또는 직접 지정한 학습 데이터 저장 폴더
- `.env` 등 실제 계정 연결 정보가 들어 있는 파일
- 원본 PDF·이미지, 본인에게만 이용 권한이 있는 학습 자료

각 사용자는 **나의 문제은행 → 새 학습팩 만들기**에서 본인의 개념과 문제를 입력하면 됩니다. **JSON 내보내기**로 학습팩만 전달하고, 받은 사람은 **JSON 파일로 가져오기**에서 자기 문제은행에 저장합니다. 풀이·복습·계획 기록은 포함되지 않습니다. 해당 자료를 공유할 권한이 있는지 먼저 확인하세요. 자세한 순서는 [문제은행 사용 안내](QUESTION_BANK.md)를 참고하세요.

## 향후 온라인 독립 운영

온라인 연동이 준비되면 각 운영자는 자기 호스팅·DB 프로젝트를 만들어 본인 계정을 설정하는 방식을 사용할 수 있습니다. 앱 코드만 공유하며 데이터·계정·비밀값은 설치본마다 분리합니다. 현재 제공하지 않는 자동 설치나 원클릭 배포가 이미 동작하는 것처럼 안내하지 않습니다.
