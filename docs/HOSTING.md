# 무료 온라인 운영 안내

온라인에서 함께 쓰려면 앱이 인터넷에 연결된 호스팅 서비스에서 실행되어야 합니다. 다만 작은 개인 서비스는 업체가 제공하는 **무료 사용량 안에서 월 이용료 0원으로 시작하는 방법**이 있습니다. 운영자가 직접 서버 장비를 사거나 PC를 계속 켜둘 필요는 없습니다.

**현재 AstraAI 배포본은 개인 PC 설치용입니다.** 이 문서는 무료 서비스 선택 안내이며, 지금 코드를 그대로 올리면 온라인 서비스가 완성된다는 뜻은 아닙니다. 실제 로그인과 온라인 저장 기능을 갖춘 버전이 필요합니다.

## 어떤 방식을 선택하면 되나요?

| 목적                                    | 방식                                          | 비용과 현재 지원                                            |
| --------------------------------------- | --------------------------------------------- | ----------------------------------------------------------- |
| 내 PC에서 공부하기                      | [개인 PC 설치](INSTALLATION.md)               | 호스팅 비용 없음. 지금 사용 가능                            |
| 다른 사람이 자기 학습실 운영하기        | 각자 코드를 받아 [독립 설치](SELF_HOSTING.md) | 각자의 PC에 설치하면 호스팅 비용 없음. 지금 사용 가능       |
| 내 PC를 꺼도 학습자들이 링크로 접속하기 | Vercel Hobby + Supabase Free                  | 무료 한도 내 운영 가능. AstraAI의 온라인 연동은 아직 미지원 |

## 권장 무료 구성

- **Vercel Hobby**: 앱을 실행하고 접속 주소를 제공합니다. 개인·비상업용 서비스에 사용할 수 있습니다.
- **Supabase Free**: 로그인과 데이터베이스를 제공합니다. 학습팩과 사용자별 학습 기록을 보관하는 역할입니다.
- **기본 제공 주소**: 제공되는 `vercel.app` 주소를 사용하면 별도 도메인을 구매할 필요가 없습니다.

사용자는 이 구성에서 하나의 접속 주소로 들어가 자기 계정으로 학습하게 됩니다. 운영자의 PC가 꺼져 있어도 호스팅 서비스가 동작합니다. 앱에서 유료 AI API를 호출하지 않으므로 해당 API 비용은 발생하지 않습니다. 관리자가 별도로 이용하는 ChatGPT 요금제와는 구분됩니다.

## 무료 범위와 주의할 조건

2026-11-07 공식 안내 확인 기준입니다. 실제 가입·운영 시 해당 페이지의 최신 조건을 다시 확인하세요.

| 서비스                                              | 확인한 무료 조건                                          | 운영에 영향을 주는 제한                                                               |
| --------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| [Vercel Hobby](https://vercel.com/docs/plans/hobby) | 개인·비상업용 무료 플랜. 월 Fast Data Transfer 100GB 포함 | CPU·요청 수 등에도 별도 한도. 대부분의 한도 초과 시 해당 기능 사용 재개까지 대기 필요 |
| [Supabase Free](https://supabase.com/pricing)       | 월 $0, DB 500MB, egress 5GB, 파일 저장 1GB 포함           | 활성 프로젝트 최대 2개. 1주일 비활성 시 프로젝트 일시 정지                            |

학습자 3명과 텍스트 중심 JSON 자료는 소규모 사용에 해당하지만, 사용자 수만으로 실제 사용량을 보장할 수는 없습니다. 자료 크기·접속 빈도·요청 수에 따라 달라집니다. 무료 플랜은 무제한 사용이나 항상 켜져 있는 상태를 보장하지 않습니다.

비용 0원을 유지하려면 무료 플랜을 선택하고, 유료 업그레이드·추가 리소스·유료 도메인을 신청하지 않으며, 각 서비스의 사용량과 제한 상태를 확인하세요. 제한에 도달했을 때 유료 전환 대신 사용량을 줄이거나 재개를 기다리는 방식으로 운영할 수 있습니다.

## 현재 코드를 바로 올릴 수 없는 이유

현재 앱에서는 계정을 직접 선택해 관리자로 전환할 수 있습니다. 인터넷에서 실제 사용자를 확인하는 로그인 기능은 아직 없습니다. 또한 기록을 PC 안의 파일에 저장하기 때문에 무료 호스팅에 복사하는 것만으로 기록이 안정적으로 보관되지 않습니다.

온라인 사용을 지원하는 버전에서는 실제 관리자/학습자 로그인, 사용자별 접근 권한, 온라인 기록 저장, 각 설치본의 관리자 설정을 먼저 갖춰야 합니다. 이 준비가 끝나면 운영자는 자신의 무료 서비스 계정을 연결해 자기 주소로 운영할 수 있습니다. 상세 구현 항목은 [온라인 전환 계획](development/ONLINE_ROADMAP.md)에 모았습니다.

현재 버전에 적용할 수 없는 배포 버튼이나 따라 해도 완료되지 않는 배포 명령은 제공하지 않습니다. 온라인 실행 검증이 완료되면 이 문서에 실제 설치·계정 설정·배포 순서를 추가합니다.

## GitHub에 코드를 올리면 앱도 켜지나요?

GitHub 저장소는 코드를 보관하고 내려받는 곳입니다. 저장소 URL을 공유해도 AstraAI 서버가 실행되지는 않습니다.

GitHub Pages처럼 정적 파일만 제공하는 호스팅은 무료이지만, 현재 앱의 서버 채점과 기록 저장 기능을 그대로 실행할 수 없습니다. 현재 기능을 유지하려면 웹 실행과 데이터 저장을 함께 지원하는 구성이 필요합니다.

## 다른 운영자도 무료로 운영할 수 있나요?

온라인 연동을 제공하는 버전이 준비되면 다른 사람도 **자기 Vercel·Supabase 계정과 자기 프로젝트**를 사용해 독립적으로 운영하는 구조를 목표로 합니다. 원래 운영자의 관리자 계정·키·사용량을 함께 쓰는 방식이 아닙니다. 각 운영자는 자신의 프로젝트의 무료 한도와 이용 조건을 관리합니다.

개인 PC에 독립적으로 설치하는 방법은 지금도 사용할 수 있습니다. [독립 설치·코드 공유 안내](SELF_HOSTING.md)를 참고하세요.
